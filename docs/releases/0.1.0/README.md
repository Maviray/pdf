# Release 0.1.0: Foundations and MVP layout

**Status:** in progress, updated 2026-11-19.

Release 0.1.0 carries phases P0 and P1 of the [design document](../../design/Maviray.Pdf-Design-Document.md). P0 has no public API, so 0.1.0 is the first release with one.

| Work item | Scope | Status |
| --- | --- | --- |

| P0.1 | PDF object model and serialization | Not started. The issue opens when the spec is approved. |
| P0.2 | Streaming file writer, checked by qpdf and poppler | Not started |
| P0.3 | Content-stream builder, with rectangles | Not started |
| P0.4 | Helvetica text | Not started |
| P0.5 | Hello-world gate and the first viewer check | Not started |
| P1 | MVP layout | Specified after P0 |

macOS Preview isn't checked in P0, because no Mac is available. The 0.1.0 release check covers it if a Mac is available by then, and otherwise records it as not checked.
